## Finding 5: LOR_FAKE_NOW on the test server cannot draw Today at 00:05
Recommendation: fix now
lor-zj7x's Done when says the test server takes `LOR_FAKE_NOW` "so Today can be drawn at 00:05, 09:00, 15:00 and 21:30 from the same data." lor-nde9 then shoots Today at those four clock times. Scope names `src/shared/localTime.ts` "or where now is taken."

The page then throws that value away: `useNow` in `src/routes/index.tsx` lines 33–40 initialises from `t.now` and on mount sets `Date.now()` every 20s. Remaining, recorded, next event and the DayArc (lines 97–129) all read that client clock. `__root.tsx` has its own `Date.now()` ticker for the chrome.

A server-only env var, even if threaded through `localTime.ts`, leaves the hero on wall-clock time. The fake clock has to be one value in the test server *and* the page (and Playwright, if the shot script stubs the browser clock), and still ignored on any database but `life_on_rails_test`. Name those call sites in lor-zj7x.
