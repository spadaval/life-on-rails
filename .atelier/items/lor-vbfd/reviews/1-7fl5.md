## Finding 1: Show the translucent swatches over the selected wallpaper
Recommendation: fix now

`android/homecore/src/commonMain/kotlin/com/spadaval/lor/lab/KitSheet.kt:115` puts `Swatches(glazes)` inside `Section("Colours")`; `Section` paints an opaque `PanelFace` at line 162. Every alpha swatch therefore composites over that panel, despite the label and Report saying it is over the wallpaper. The wallpaper picker cannot show how the state fill, scrim, veil or folder glass behaves on a pale or mixed background, which is precisely what these samples are meant to expose.

I reproduced this on cover with dark and pale selected. At the scrim sample's centre, screenshot pixel (410,700) remains RGB (7,7,10), and all five glaze samples remain unchanged. A nearby exposed wallpaper pixel changes from (14,11,23) to (237,232,223). See `/tmp/lor-vbfd-review-sol/cover-dark.png` and `cover-pale.png`.

Give the translucent samples a wallpaper backing, or move them outside the opaque section, while keeping their labels readable. Verify that changing the wallpaper changes the alpha samples themselves.

## Finding 2: Refresh the draw marker when the raw hash changes to an equivalent link
Recommendation: defer

`android/homecore/src/wasmJsMain/kotlin/com/spadaval/lor/lab/Main.kt:97` keys `LaunchedEffect` only on the parsed `LabLink`, but writes the raw `window.location.hash` into `data-drawn`. Starting at `#current/home-full` and changing the hash to the equally valid `#current/home-full/cover/dark` does not change that key, so the marker stays `#current/home-full` indefinitely. The same happens when navigating from the default screen to an unknown version that falls back to it. The page's declared draw-marker contract and the catalogue's `data-drawn === location.hash` wait then disagree.

I reproduced both stale values in `/tmp/lor-vbfd-review-sol/behavior.json`; reloading the unknown-version URL sets the marker correctly. Retain the raw hash alongside the parsed state and key the completion signal on that value, recording the hash for the render being acknowledged. This can be deferred because the current catalogue uses distinct canonical links and its four captures passed.
