## Finding 1: Keep cold fixture launches from starting the real app services
Recommendation: fix now

`android/app/src/main/java/com/spadaval/lor/LorApp.kt:73-75` only skips startup in `:lab`. The required command first starts HomeActivity in the main process, so Application.onCreate schedules SyncWorker and calls LiveUpdates.start before HomeActivity can inspect `lab_state` and hand off. LiveUpdates starts the persisted T3 connection (`live/LiveUpdates.kt:56`); finishing HomeActivity does not stop it. SyncWorker can collect and upload actual device data using the saved server settings. The Report acknowledges this, and my cold launch at 16:45:28 logged new WorkManager scheduling in main-process PID 7828 before `LabState: fixture overfull` in PID 7854. Earlier cold-launch logs also show SyncWorker executing.

This does not meet the Done when requirement that opening a fixture touches no server or T3. Isolating only the final drawing process leaves the side effects in its entry process. Defer real-service startup until a real app entry needs it, or arrange the debug entry so a fixture launch never boots those services. Preserve normal app startup and add a check covering the cold entry, not only fixture resolution and the release stub.

## Finding 2: Make the JSON export work on the published lab's HTTP origin
Recommendation: fix now

`android/homecore/src/wasmJsMain/kotlin/com/spadaval/lor/lab/Main.kt:158-162` unconditionally calls `navigator.clipboard.writeText`. The published lab is served at `http://buildbot:3847/lab/launcher/`; unlike localhost development, that HTTP hostname is not a secure context and has no clipboard API. In Chrome with the actual bundle and lab CSP on `http://lor-review.test/lab/launcher/`, `isSecureContext` was false and `typeof navigator.clipboard` was `undefined`. Clicking Copy JSON emitted `NullPointerException: null` and exported nothing. The localhost-only checks miss this delivery path.

Provide a JSON export/manual-copy path that works on the existing HTTP hosting. Where the clipboard API is available, await its result before showing Copied and surface rejection instead of reporting success. Verify the published-origin case as well as localhost.
