The agent keeps this page. When he says "don't tell me about things like this" (or "do"), change it right away and confirm in one line. Only a thread where he is talking changes it; unattended runs follow it and never edit it.

- Sensitive information (therapy notes, health, finances, codes): don't send it unless he explicitly asks. Say where to read it instead.
